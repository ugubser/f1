How to sign in securely

In your own terminal, open this project and run npm run f1:login. Enter your F1 TV account email and password at the prompts. The password is hidden and never saved. Only F1 receives your credentials over HTTPS; the subscription token is saved privately outside this project.

Return here and click Connect. When the token expires, run the sign-in command again. To remove the saved sign-in, run npm run f1:logout. Never paste credentials or tokens into this chat.
